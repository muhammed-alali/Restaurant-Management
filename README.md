# نظام إدارة المطعم الداخلي — مطعمنا (Restaurant Management System)

نظام ويب متكامل لإدارة العمليات الداخلية للمطاعم، مبني بأحدث التقنيات وأفضل الممارسات البرمجية وفق مبادئ **SOLID** والتصميم النظيف (Clean Architecture).

> 🐳 **التشغيل عبر Docker:** راجع [DOCKER.md](./DOCKER.md) لخطوات النشر الإنتاجي والتطويري والمنافذ المستخدمة.

---

## 🌟 نظرة عامة على النظام

تم تصميم هذا النظام الداخلي لخدمة طاقم العمل في المطعم (الكاشير، الصالة، الشيف في المطبخ، ومناديب التوصيل، ومدير النظام) وفق دورة عمل متكاملة:
1. **إنشاء الطلب:** يقوم الموظف بإنشاء طلب جديد (داخلي مع تحديد الطاولة، سفري، أو توصيل).
2. **المطبخ (KDS):** يظهر الطلب فوراً في شاشة المطبخ ليبدأ الشيف بالتحضير.
3. **الجاهزية:** بمجرد انتهاء الطهي، يُعلّم الشيف الطلب كـ "جاهز".
4. **التسليم:** يقوم موظف الصالة أو مندوب التوصيل بتسليم الطلب وإتمامه، وتحرير الطاولة تلقائياً.

---

## 🚀 التقنيات المستخدمة (Tech Stack)

- **Framework:** Next.js (App Router)
- **Language:** TypeScript (Strict Type Checking)
- **UI Components:** Ant Design (`antd`) مع دعم RTL والتعريب الكامل.
- **Styling & Theming:** `styled-components` + centralized design tokens في `src/theme/theme.ts`.
- **Database & ORM:** SQLite محلي مع Prisma ORM.
- **Authentication & RBAC:** Auth.js / NextAuth v5 مع تشفير كلمات المرور بـ `bcryptjs` وحماية العمليات بالصلاحيات.
- **Validation:** Zod للتحقق الصارم من مدخلات النماذج والـ API.
- **Assets:** خطوط وأيقونات وصور أطعمة وشعار محلي بالكامل دون أي اعتماديات خارجية أو إنترنت وقت التشغيل.

---

## 📑 الأقسام الخمسة الرئيسية

1. **الطلبات (`/orders`):** جدول تفصيلي بجميع الطلبات، فلاتر الحالات، إنشاء طلب جديد، درج تفاصيل الطلب، وطباعة الفاتورة.
2. **الطاولات (`/tables`):** شبكة طاولات تفاعلية، تمييز الطاولات المتاحة/المشغولة/المحجوزة، بدء طلب لطاولة متاحة، وعرض طلب الطاولة المشغولة.
3. **المطبخ (`/kitchen`):** لوحة KDS مقسمة إلى 3 أعمدة (جديد، قيد التحضير، جاهز) مع تحديث ومزامنة فورية وتوضيح ملاحظات الطهي.
4. **المنيو (`/menu`):** بطاقات الأطعمة، التحكم في توفر الوجبات، تعديل الأسعار، وإضافة أصناف جديدة.
5. **التوصيل (`/deliveries`):** إدارة وتتبع طلبات الدليفري، تعيين المناديب، وتحديث مراحل التوصيل حتى الاستلام.

## 👥 حسابات الدخول التجريبية (Demo Accounts)

النظام مزود بأزرار دخول سريع بنقرة واحدة في صفحة الدخول `/login`:

| الدور (Role) | اسم المستخدم | كلمة المرور | الصلاحيات |
|---|---|---|---|
| **المدير (ADMIN)** | `admin` | `admin123` | كامل الصلاحيات لجميع الأقسام والإعدادات |
| **الكاشير (STAFF)** | `staff01` | `staff123` | إنشاء وإدارة الطلبات، الطاولات، والتوصيل |
| **الشيف (CHEF)** | `chef01` | `chef123` | شاشة المطبخ وإدارة حالات الطهي |
| **التوصيل (DELIVERY)** | `delivery01` | `delivery123` | متابعة وتحديث طلبات التوصيل المعينة له |

## 🛠️ التثبيت والتشغيل المحلي

### 1. تثبيت الحزم
```bash
cd restaurant-app
npm install
```

### 2. إعداد قاعدة البيانات وتوليد البيانات الأولية
```bash
# إنشاء جداول قاعدة البيانات SQLite
npx prisma db push

# زرع الحسابات والأطعمة والطاولات والطلبات التجريبية
npm run prisma:seed
```

### 3. تشغيل خادم التطوير
```bash
npm run dev
```

افتح المتصفح على: `http://localhost:3000` للدخول للنظام.
